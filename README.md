<h1 align="center">人大校园网助手</h1>
<p align="center">RUC Web Helper</p>
<p align="center">自动登录 RUC-Web，清楚了解每一天、每台设备的校园网用量。</p>

每次打开电脑，连上 RUC-Web 后，还要打开登录页、输入账号密码，才能开始上网。到了月底，想知道流量都花在哪天、哪台设备上，又很难从一条条上网记录中看出答案。

**人大校园网助手**把这两件事放在一个简洁的桌面应用里：保存账号后自动登录，用图表整理流量数据。

目前支持 **Windows · 中国人民大学校园网**，对应登录入口为 [go.ruc.edu.cn](https://go.ruc.edu.cn/)。本项目由个人开发，是非官方开源工具。

![首页：连接状态、剩余流量、账户余额和在线设备](docs/images/overview.png)

## 开机后，少一步手动登录

在设置里保存校园网账号和密码，开启「自动登录校园网」与「开机自启」。以后登录 Windows，助手就会在后台运行；接入校园网后，使用保存的账号完成登录，不用每次再打开浏览器。

- **开机自启**：在托盘中运行，无需每次手动打开软件。
- **自动登录**：保存账号密码后才可开启，由你决定是否启用。
- **唤醒后恢复连接**：电脑休眠再唤醒时，重新检查登录状态。
- **手动控制**：首页也可以连接或断开网络。

![设置：开机自启、自动登录和休眠唤醒后恢复连接](docs/images/settings.png)

关闭窗口后，助手会继续在托盘运行。需要查看数据时，从托盘打开窗口即可。

## 流量用了多少，用在哪里

首页先回答最常用的问题：**还剩多少流量，余额还有多少？**

流量条分成「已用流量」「剩余免费流量」「剩余收费流量」三个区域，把免费额度和余额能支持的收费流量分开显示。快用完时，还可以开启低流量提醒。

想进一步了解用量，打开「统计」，先选月份，再选全部设备或某一台设备。

### 按月看：整体用量与每天的变化

月统计展示本月估算用量、日均用量和最高用量日。

**饼图**帮助你比较电脑、手机、平板的流量占比；**每日柱状图**帮助你找到用量较高的日期。同一台设备在两种图表中使用相同颜色，每根柱子也会按设备分色，方便对应查看。

![月统计：设备用量占比与按设备分色的每日流量柱状图](docs/images/monthly-statistics.png)

### 按日看：某一天是哪台设备用得多

点击月统计中的某根柱子，或切换到「日统计」选择日期，就能查看当天的估算用量和设备占比。

例如，某天流量突然增加，可以先看是哪台设备占比较高，再到「会话统计」查看具体的上网时段和用量。

![日统计：选定日期的流量总量与各设备占比](docs/images/daily-statistics.png)

**关于统计数据：**图表根据已结束的上网记录计算。一次连接如果跨过午夜，会按连接在各天持续的时长平均分摊流量；仍未结束的连接暂不计入图表。因此，每日用量是估算值，不能精确还原每个时刻实际消耗的流量，也可能与首页当前账期的已用流量不同。具体计算方式见 [流量统计说明](docs/statistics.md)。

## 还有一些日常会用到的小功能

- **给设备起名字**：把设备命名为「我的电脑」「手机」等，统计图中也会显示这些名字。
- **管理在线与历史设备**：查看在线状态和 MAC 地址；暂时不想看到的设备可以忽略，之后也能恢复。忽略设备不会删除它的流量统计。
- **选择喜欢的外观**：浅色、深色，或跟随系统自动切换。

## 第一次使用

软件采用便携版形式，无需安装。正式版本发布后，可在 [Releases（发行版）](https://github.com/FengNKT/ruc-web-helper/releases) 中获取。

1. 将便携版解压到一个准备长期存放的文件夹，运行 `人大校园网助手.exe`。
2. 连接校园网，打开「设置 → 管理账号」，保存学工号和数智人大密码。
3. 开启「自动登录校园网」；希望开机后自动运行，再开启「开机自启」。
4. 回到首页检查连接状态，打开「统计」查看用量。

账号密码保存在本地，密码经过加密，仅当前 Windows 用户可解密。软件与配置放在同一目录；移动软件时，请一起移动整个文件夹。

程序需要 Windows 的 WebView2 Runtime。如果无法打开，请先检查是否已安装该运行环境。更多操作说明见 [使用指南](docs/usage.md)。
