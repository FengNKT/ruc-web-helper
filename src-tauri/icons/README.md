# 应用图标

朱红色圆角方形内，以白色“人”字和两道网络信号弧线表达校园与网络连接。图形为原创，不使用学校校徽。

- `ruc-web-helper.svg`：可编辑矢量源文件。
- `icon.png`：512 像素应用图标。
- `icon.ico`：包含 16、20、24、32、40、48、64、128、256 像素的 Windows 图标。
- `../../public/app-icon.svg`：网页预览图标，由导出脚本同步。

运行 `npm run icons` 可重新导出；需要 Microsoft Edge、Python 和 Pillow。高清图及检查用尺寸输出至已忽略的 `test-results/icons/`，不提交生成的预览。
