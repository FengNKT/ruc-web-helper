# V1.2.0 本地实现与验证

本记录汇总 V1.2.0 发布前的实现与验证结果。

## 已实现

- 数据统一保存在 `%LOCALAPPDATA%\cn.ruc.webhelper`；旧目录数据先完整复制后启用，原数据保留，现有用户数据不会被旧副本覆盖。更新器支持独立下载目录和旧版启动确认。
- 本机多账号加密存储、账号备注、添加、编辑、删除与切换认证。
- 旧版单账号按第一条账号兼容读取，修改时写入多账号结构。
- 设置页顶部集中管理账号，通过设置导航进入。
- 设置页可确认清除当前用户全部数据，关闭自启后退出再删除缓存；隔离脚本测试覆盖退出等待、文件占用重试、外部目录链接保护及任务自清理。保留无账号信息的重置标记，防止旧副本和旧凭据自动回流。未对真实用户数据执行清除。
- 设置页提供内置“使用与隐私说明”，直接使用 `docs/privacy.md` 编译内嵌；全文、表格、深浅色、320px 布局、Esc 关闭与焦点恢复均已验证。
- 概览用一个控件展示连接状态、真实在线账号与 IP；已登记时自动对齐，无额外提示，未登记时提供预填记录入口。
- 可跳过且记住选择的首次引导；在线状态不视为已保存凭据。
- 首次运行默认登记开机自启，已有关闭状态不强制重设；注册失败不写入首次设置，便于重试。
- 自动登录默认开启，开关与账号配置独立；账号区可选择默认自动登录账号，网络状态刷新与手动切换不会改变此选择。无账号时不执行自动登录。
- 启动时登录，最多等待网络五分钟；成功或手动下线后不再自动认证，完整重启才产生新任务。
- 状态检测与低流量提醒独立工作；凭据异常时可先备份原文件再重新配置。

## 已完成的验证

- `npm test`：11 项通过。
- `cargo test --manifest-path src-tauri/Cargo.toml --locked`：33 项通过，2 项外网测试按原有设置忽略。
- `node tests/e2e/smoke.cjs`：通过；覆盖原有功能以及多账号新增、编辑、切换、取消、删除、认证失败后的状态、无凭据但在线、在线身份不一致、引导跳过与开始设置、异常凭据恢复、320–1040px 布局。
- 学校 `E2901: (Third party 1)bind_user2: ldap_bind error` 映射为数智人大密码错误，覆盖各错误详情字段；其他 E2901 服务故障不误判为密码错误。
- 认证测试通过本机 HTTP 模拟服务验证：注销失败不继续登录、密码错误不回退旧账号、目标身份不一致不报成功、同账号在线不重复注销。
- 凭据测试覆盖旧格式兼容、独立保存密码、空密码保留、默认自动登录账号独立存储与旧格式迁移、学工号去重、选用和删除、公开摘要不含密码、异常文件备份。
- `npm run version:check`：六处版本字段均为 1.2.0。
- 更新器隔离集成测试：更新成功、启动失败回退、未确认回退和篡改拦截均通过，用户数据保持不变，EXE 目录无配置或临时文件残留；使用临时测试签名密钥。
- `git diff --check`：通过。
- 使用虚构数据更新说明截图，并检查设置页视觉布局。
- 本机真实数据已从旧交付目录复制到用户目录：账号、设置、设备档案、旧设备名称与更新设置文件校验一致，WebView 使用新目录；旧副本归档到 `.local/retired-delivery-data/`，交付只保留 EXE。

## 验证边界

自动测试未提交真实校园网认证、注销或其他设备下线请求，也未启动本地构建来接管现有校园网连接。真实校园网的账号限制、开机自启和休眠场景仍需在实际环境人工验收；本次不将模拟测试等同于真实学校服务验证。

本地构建命令为 `npm run desktop:build`，输出 `src-tauri/target/release/ruc-web-helper.exe`，不生成或上传发行包。
