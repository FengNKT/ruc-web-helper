# V1.2.1 本地验证

本记录包含自动化测试结果及尚未完成的真实设备验证。

## 行为

- 设置项改为“自动登录校园网”，说明为“开机启动时及休眠唤醒时自动登录校园网”。沿用原有开关和默认自动登录账号。
- 监听 Windows `PBT_APMRESUMEAUTOMATIC`，主窗口隐藏到托盘时也有效。不将重新打开托盘窗口、普通状态刷新或轮询延迟视为唤醒。
- 每次启动或唤醒创建一次登录任务，先检查实际在线状态；在线时保留连接，离线时使用默认自动登录账号。网络未就绪时最多等待五分钟。
- 开关关闭或没有账号时不自动认证。主动下线取消本次任务，后续普通轮询不重连；下次启动或唤醒可创建新任务。密码错误等认证拒绝结束本次任务。
