# 人大校园网助手 1.0.0

首个正式版本，适用于 Windows x64、中国人民大学校园网。

## 主要功能

- 保存账号后自动登录 RUC-Web，支持开机自启、休眠唤醒后恢复连接。
- 首页查看连接状态、流量与余额，区分已用流量、剩余免费流量和剩余收费流量。
- 按月、按日、按设备查看流量图表，并查看已结束的上网会话。
- 查看在线和历史设备、MAC 地址，支持命名、忽略和恢复。
- 支持浅色、深色及跟随系统外观。

## 下载与使用

首次使用请下载文件名以 `_portable.zip` 结尾的便携包，解压后运行 `人大校园网助手.exe`，无需安装。进入“设置 → 管理账号”保存学工号和数智人大密码，再按需开启自动登录与开机自启。

独立 `.exe` 供手动替换已有程序使用。替换前请从托盘退出助手，保留原目录中的账号、设置与设备档案。`SHA256SUMS.txt` 用于核对下载文件是否完整。GitHub 的 Source code 下载项是源码，不是可直接运行的软件。

## 说明

- 每日用量由已结束会话按各天在线时长分摊估算，正在进行的连接暂不计入图表。
- 账号密码保存在本地，密码经 Windows 用户范围加密。
- 本版本尚未提供应用内自动更新，后续版本暂需手动下载替换。
