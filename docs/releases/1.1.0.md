# 人大校园网助手 1.1.0

本次更新的核心功能是 **软件自动更新**。

- 自动检查 GitHub 正式版本，有新版本时在助手中提示。
- 设置页支持手动检查、查看更新说明、下载更新与取消下载。
- 下载后校验签名和文件完整性，点击“重启并更新”完成替换。
- 继续使用便携版，无需安装包；账号、设置和设备名称会保留。
- 新版启动失败时尝试恢复原程序。
- 更新请求默认跟随 Windows 系统代理，可在设置中改为直接连接。校园网登录和查询继续直连。

## 从 1.0.0 升级

1.0.0 尚未包含自动更新，需要手动升级这一次：从本页下载 EXE，退出托盘中的助手后，用它替换原目录中的程序，并保留原文件名和其他文件。也可以下载便携版 ZIP 后只提取其中的程序文件。

从 1.1.0 开始，后续带有签名更新文件的正式版本可以在应用内升级。自动检查默认开启；软件不会自动下载或未经确认重启。

## 下载哪个文件

- 首次使用：`ruc-web-helper_1.1.0_windows-x86_64_portable.zip`，解压后运行 `人大校园网助手.exe`。
- 已有 1.0.0：`ruc-web-helper_1.1.0_windows-x86_64.exe`，用于替换原程序。
- `SHA256SUMS.txt` 用于核对下载完整性；`update.json` 和 `update.json.sig` 供客户端自动更新使用。

适用于 Windows x64、中国人民大学校园网。本项目是非官方开源工具，采用 AGPL-3.0-only 许可证。
