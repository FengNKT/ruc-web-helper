# 使用与隐私说明

更新日期：2026年10月18日

本说明适用于人大校园网助手（RUC Web Helper）当前 Windows 版本，介绍软件用途、数据处理方式及可用的控制方法。请在添加账号、使用设备管理或开启自动功能前阅读。不同版本的功能可能有所不同，请结合所用版本的界面与使用指南查看。

## 一、项目身份与使用范围

本软件为个人开发的非官方开源工具，与中国人民大学及校园网认证系统供应商无隶属、合作或背书关系，不代表学校提供服务或作出承诺。

软件用于通过学校现有认证与查询流程登录校园网、查看流量余额、管理账号下的设备及统计上网会话。请仅使用本人账号，或在账号持有人合法授权且学校规则允许的范围内操作。账号持有人的同意不代表可以突破学校系统的访问控制。

请勿利用本软件或其修改版本获取他人账号、密码、会话或数据，实施越权访问，绕过认证、计费或设备限制，或干扰校园网服务。使用时仍应遵守适用法律法规及学校有效的账号、网络管理规则。本说明不构成学校对第三方客户端或任何具体操作的授权。

## 二、软件处理哪些信息

软件主要在本机处理以下信息，用于完成你选择的功能：

| 信息类别 | 主要内容 | 用途与处理方式 |
| --- | --- | --- |
| 账号凭据 | 学工号、密码、账号备注、选用及默认自动登录账号、密码错误标记 | 保存多账号配置，在手动或启动登录时使用；以加密账号文件保存在本机 |
| 当前网络与账号状态 | 当前校园网账号、IP、在线状态、流量、余额等接口返回信息 | 显示连接、额度和提醒，判断是否需要执行启动登录任务 |
| 设备信息 | MAC、IP、设备名称、系统类型、在线状态、会话标识及相关时间 | 显示设备、识别当前设备，并提交你确认的设备下线操作 |
| 本地设备档案 | 账号分组摘要、MAC、学校名称和本地名称、系统类型、忽略状态、首次及最近记录时间、已发现的记录月份等 | 在设备离线后保留名称和发现信息，为设备页与统计关联设备；保存在本地文件中 |
| 历史上网会话 | 学校返回的会话起止时间、用量、设备 MAC、IP 及接口包含的其他会话字段 | 计算月、日及设备用量；完整明细在程序内存中处理，其中部分发现信息会更新到本地设备档案 |
| 设置与界面偏好 | 自启动、启动时自动登录、提醒、主题、首次引导状态等 | 保存你的使用选择；界面运行环境还会产生本地缓存 |
| 更新信息 | 更新开关、网络方式、检查时间、版本说明、版本缓存、下载和恢复信息等 | 检查、下载和安装你选择的软件更新，相关文件保存在本机 |

设备档案中的账号摘要用于区分账号，不是加密或不可逆识别的匿名化措施；MAC、名称及时间信息仍应妥善保护。本地设备命名和忽略操作作用于助手显示，不会修改学校设备名称，也不会删除学校记录。

软件的流量统计使用校园网上网会话数据，不通过抓取你访问的网页内容或通信正文生成统计。本版本未设置开发者账号服务器、账号云同步、广告统计或主动向开发者上传校园凭据和上网明细的功能。

## 三、信息会发送到哪里

### 学校校园网服务

登录和查询访问 `https://go.ruc.edu.cn`。认证时，软件使用账号、密码及学校下发的参数生成认证请求，向学校提交必要的认证数据；查询和设备操作会提交当前账号、会话信息及所需的日期、分页或设备标识等参数。

认证后的查询使用学校发放的 Cookie、页面令牌等会话信息。学校会按照其系统规则处理认证、查询和操作请求，并可能保存相应记录。助手不能控制学校服务的数据保存期限，也不能删除学校保存的账号或上网记录。

校园网请求通过 HTTPS 发送并校验证书，认证与查询使用直接连接，不采用更新功能的代理设置。VPN、系统路由、终端安全环境仍可能影响实际连接。

### GitHub 更新服务

本版本默认自动检查 GitHub 上的项目发行版。你可以在“设置 → 软件更新”关闭自动检查，也可手动检查。自动检查不会自动下载新版或重启程序；下载和重启更新由你操作。

检查与下载会联系 GitHub API、发行版下载地址及其允许的下载域名。请求不主动附带校园账号、密码、设备 MAC 或上网明细，但对端可能接触请求来源 IP、时间、请求地址、含软件版本的客户端标识等网络信息；使用代理时，请求来源 IP 可能是代理出口 IP。更新请求默认跟随系统代理，也可改为直接连接。

关闭自动检查会停止后续自动检查，不会撤回已经发送的请求；手动检查、下载或打开项目网页仍会产生相应网络访问。GitHub 及其基础设施可能在境外处理相关请求，接收方如何保存网络记录由其自身规则决定。

### 外部网页与主动反馈

通过软件打开学校网站、项目发行页等链接时，由系统浏览器访问相应服务，浏览器及对方网站适用各自的设置和规则。

向项目提交问题或截图属于你主动提供信息。公开问题区的内容可能被其他人查看、复制或检索。请不要提交密码、Cookie、认证令牌、完整账号文件或未脱敏的网络响应；截图应遮盖学工号、IP、MAC、余额及其他不希望公开的信息。

## 四、自动功能与操作影响

- **自启动：**“开机自启”默认开启，首次运行时自动登记 Windows 启动项，此后登录当前 Windows 用户账户时在托盘运行。可在设置中关闭；已有用户关闭的选择会保留。
- **启动登录：**“启动时自动登录”默认开启，但没有配置账号时不会提交登录。第一个保存的账号会成为默认自动登录账号；保存账号本身不立即提交认证。启动时已有连接会保留现有连接，不自动注销接管；网络暂未就绪时，启动任务最多等待五分钟，密码错误、欠费或限制等会结束任务并提示。
- **已有在线会话：**即使没有保存密码，软件仍可依据本机当前校园网会话查询在线账号、流量和设备；访问统计时还会查询相应历史记录。请在共享或借用电脑上核实账号归属。关闭启动登录不会停止状态查询；不希望继续查询时，请从托盘退出软件。
- **账号切换与设备下线：**确认切换账号会先下线本机当前账号，再尝试登录目标账号，期间可能断网；设备下线会中断所选设备的校园网连接。请确认有权执行该操作。
- **主动断开与退出：**主动断开会取消本次启动登录任务并保持离线；下次完整启动后仍会按设置尝试登录。关闭窗口会隐藏到托盘，退出需通过托盘菜单操作。退出软件不会主动注销学校的校园网会话。
- **删除默认账号：**当前版本删除默认自动登录账号后，会改用剩余的第一个账号。若不希望发生后续自动登录，请先关闭“启动时自动登录”，再检查默认账号选择。

成功登录后的意外掉线、官网下线或休眠唤醒，当前版本不会因此自动重新认证。自动更新检查与校园网启动登录是独立开关。

## 五、本地保存与安全边界

用户数据默认保存在当前 Windows 用户的 `%LOCALAPPDATA%\cn.ruc.webhelper`。移动或替换 EXE 不会自动清除该目录。

| 文件或目录 | 保存内容 |
| --- | --- |
| `account.enc` | 采用 Windows 当前用户范围 DPAPI 加密的账号凭据和账号配置 |
| `account.enc.recovery-*` | 凭据恢复操作保留的原始加密账号文件备份，可能包含当时保存的多个账号 |
| `settings.json` | 软件设置，不包含密码 |
| `devices.json` | 本地设备档案，以 JSON 保存，未采用账号文件的 DPAPI 加密 |
| `device-names.json` | 旧版本迁移保留的设备名称信息 |
| `webview-data/` | 界面运行环境缓存与本地偏好，包括主题等 |
| `updater.json`、`.updates/` | 更新设置、版本缓存、下载文件及恢复信息 |

账号加密通常绑定原电脑和原 Windows 用户，换电脑或用户后可能需要重新填写密码。前端不会读取或回显已经保存的密码，但认证过程中程序需要在内存中使用凭据。加密不能保证抵御已取得同一 Windows 用户权限的恶意软件或被控制的终端。

首次迁移旧版本时，软件可能复制旧 EXE 同目录的数据到用户目录，并保留原文件以避免数据丢失。原目录、备份工具、同步盘或系统备份中仍可能存在其他副本。

完整历史会话明细不作为独立文件持久化，但设备档案中保留部分关联信息。当前版本没有按固定天数自动到期清理设备档案或凭据恢复备份的机制，相关文件通常保留到你主动清理。更新缓存会随更新流程变化。不要将用户数据目录上传到公开仓库或交给不可信人员。

## 六、修改设置、删除数据与停止使用

你可以在软件设置中修改账号、密码和默认自动登录账号，关闭自启动、启动登录、提醒及自动更新检查；也可以编辑本地设备名称，忽略或恢复设备显示。

“删除本机凭据”仅从当前账号配置中移除所选账号，不注销校园网、不删除学校账号，也不会自动清除设备档案、恢复备份、旧版副本或学校记录。“备份原文件并重新配置”会先保留原账号文件，再重置当前凭据配置，因此也不是彻底清除操作。忽略设备只改变显示，不删除其档案或流量统计。

在“设置 → 清除所有本地数据”点击“清除数据”并确认后，软件会关闭开机自启、退出程序，并删除当前 Windows 用户数据目录中的全部账号密码、设置、设备档案、凭据恢复备份、界面缓存及更新文件。此操作影响软件中保存的所有账号，无法通过助手撤销。清除不会主动注销校园网、删除 EXE 或删除学校端的账号与记录。

清除任务会等待程序退出并重试被占用的文件。如果仍未完成，会提示重新打开软件继续清理。为防止再次导入已清除的旧数据，用户数据目录旁会保留 `cn.ruc.webhelper.reset` 重置标记，仅记录清除状态，不保存账号、密码或设备信息。再次运行软件时会按首次使用初始化，包括默认开启开机自启；没有添加账号时不会自动登录。

该功能不删除旧版 EXE 同目录中的副本、自行备份、同步盘或系统备份，也不能撤回已经发送到学校、GitHub 或公开问题区的信息。需要删除这些副本时，请仅处理能够确认属于本软件且不再需要的文件。清除不能保证消除系统备份或存储介质上的可恢复痕迹。

也可以在关闭自启并退出软件后，手动删除 `%LOCALAPPDATA%\cn.ruc.webhelper`。仅删除 EXE 不等于清除数据；未通过软件清除功能建立重置标记时，旧版目录中的数据仍可能在下次启动时迁移回来。

## 七、统计、服务变更与责任

软件使用学校接口返回的状态和数据，但接口并非本项目控制，学校调整接口、计费规则或访问策略后，功能可能失效或需要更新。

月、日统计主要基于已结束会话，跨日流量按会话时长分摊，不能反映真实的逐日峰谷；当前在线会话可能尚未纳入。首页部分额度使用软件内设规则估算，未必适用于全部账号或未来计费方案。实际用量、余额、套餐、收费和账单应以学校官方系统及有效规则为准。

请根据实际情况确认账号切换和设备下线操作。发现异常时，可以停止相关功能、退出软件并通过学校官方入口核实。遇到凭据泄露或疑似未经授权的会话，请及时通过学校官方渠道修改密码、检查并处理在线设备。

本说明用于说明功能边界和合理使用要求，不排除或限制依法不得排除或限制的责任。软件开源许可证中的许可及保证条款，在适用法律允许的范围内生效。
