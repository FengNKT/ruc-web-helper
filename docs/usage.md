# 使用与本地数据

## 多账号与启动登录

账号列表平时只显示学工号；认证确认密码错误后，在该账号下显示红色“数智人大密码错误”。此状态在本机保存，修改密码或使用保存的密码成功认证后清除；仅刷新或检测到账号在线不会清除。

首次使用会引导设置校园网学工号和数智人大密码，也可暂时跳过。账号管理位于设置页顶部。可以保存多个账号、填写备注、编辑密码和删除本机凭据。保存本身不会提交认证或更改当前网络连接。

第一个保存的账号成为待登录账号和默认自动登录账号；新增其他账号本身不会切换网络。同一学工号不能重复添加。编辑账号时，密码框默认显示 6 个黑点；点击后清空，输入新密码并保存即可修改，取消不改变密码。未编辑密码时保存其他信息会保留原密码；更改学工号必须填写新密码。删除账号不改变自动登录开关，也不会注销现有网络。删除默认自动登录账号后，改用剩余的第一个账号；全部删除后不执行自动登录。

点击账号旁的“登录”会先将本机当前在线账号下线，再使用目标账号认证，最后核实在线身份。失败后显示真实网络状态，目标账号保留为选用账号，可手动重试；不会自动登录回原账号，也不会下线其他设备以腾出名额。

概览将连接状态、当前账号、IP 与操作合为一个控件。启动、刷新与后台状态检查都以网络实际返回的账号为准。若在线账号已登记，会同步选用该账号且不额外提示，也不会重新认证。未登记时提供“记录此账号”，预填账号但不填密码；完全未配置账号时明确提示设置凭据。记录后保持原连接，不将检测在线等同于已保存密码。离线时展示待登录账号；查询失败显示暂时无法确认，不用旧账号冒充当前在线身份。

“开机自启”默认开启，首次运行时登记 Windows 启动项；已有用户关闭的选择会保留。启用时会在用户登录 Windows 后启动程序，并在托盘中运行。移动程序后，请关闭再开启该开关，以更新启动路径。

“启动时自动登录”默认开启，使用账号配置中选定的“默认自动登录账号”，在每次启动程序时尝试登录，包括手动启动和 Windows 自启。启动时网络暂未就绪，会在最多五分钟内重试；密码错误、欠费或限制会结束本次任务并提示处理。开关与账号是否配置无关，无账号时开启也不执行登录。默认自动登录账号独立保存，刷新网络状态和手动切换不会改变它。启动时已在线则保留现有连接，并按实际在线账号同步本地信息，不自动注销接管。

关闭主窗口会隐藏到托盘；右键托盘图标可以退出。退出程序不会主动注销校园网。主动下线会取消本次启动任务及后续重试，并保持离线；可以手动登录，或下次完整启动后按设置登录。成功登录后，意外掉线、官网下线和休眠唤醒不会触发自动重新认证。重新打开托盘窗口不算重新启动。

## 设备

设备列表合并当前设备接口、本地档案和已读取历史记录中发现的 MAC，并按账号隔离。它不保证包含账号使用以来的所有设备。

设备页支持命名、MAC 展示、忽略与恢复。忽略只影响设备列表显示，不断开连接，也不移除统计数据。设备离线后仍保留档案；历史设备不能被当作在线会话下线。

在线设备只显示 IP、MAC；离线设备增加“上次在线”。各项标签、间隔号与内容采用统一留白，MAC 仅地址内容使用等宽字体。“上次在线”取已读取会话记录中最近一次会话的关闭时间，不使用当前连接的接入时间；没有已结束会话记录时显示“暂无记录”。状态尚未确认时不展示“上次在线”。

名称以 MAC 地址关联，作用于概览、设备页及统计。随机 MAC 或换网卡可能产生新的设备档案。统计中的“设备详情”可定位设备，点击空白处或按 Esc 取消高亮。

## 本地文件

从 V1.2.0 起，只需下载并运行单个 EXE。配置和缓存统一保存在当前 Windows 用户的 `%LOCALAPPDATA%\cn.ruc.webhelper`，与程序位置和工作目录无关。

首次启动时会自动复制旧 EXE 同目录中的账号、设置、设备档案、凭据备份、更新缓存和 WebView 数据；原文件保留，用户目录已有数据时不会被旧副本覆盖。移动或替换 EXE 后继续使用同一份数据。

| 文件或目录 | 内容 |
| --- | --- |
| `settings.json` | 自启动、自动登录、提醒及主题设置，不含密码 |
| `account.enc` | 使用 Windows DPAPI 加密的多账号凭据、备注和选用状态；兼容旧版单账号 |
| `account.enc.recovery-*` | 凭据恢复操作保留的原始加密文件备份 |
| `devices.json` | 本地设备名称、MAC、忽略状态及发现信息 |
| `webview-data/` | WebView2 缓存与界面显示偏好 |
| `device-names.json` | 旧版本迁移时保留的设备名称备份 |

这些文件不应提交到 GitHub。设备档案中的账号摘要仅用于分组，不是加密。

DPAPI 使用当前 Windows 用户范围；加密账号通常只能在原电脑的原 Windows 用户下解密。换电脑或用户后需重新填写账号。前端不读取或回显已保存密码。旧设置与凭据迁移使用原标识进行兼容。

校园接口由 Rust 后端通过 HTTPS 访问，校验证书，只允许学校 HTTPS 域名的重定向。VPN、代理或路由变化可能影响连接。Windows 自启动登记与 DPAPI 系统密钥由操作系统管理。

## 清除本地数据

设置页底部点击“清除数据”，确认后关闭自启并退出，删除当前用户目录内所有账号、设置、设备档案、恢复备份、缓存和更新文件。不会主动断开校园网，不删除 EXE、旧目录副本或学校记录。清除不可撤销；再次运行按首次使用初始化。程序保留不含账号信息的重置标记，阻止重新导入旧目录数据。

## 使用与隐私说明

在设置页底部点击“使用与隐私说明”旁的“查看”，可在软件内阅读完整说明。正文随程序内嵌，可离线阅读；点击“关闭”或按 Esc 返回设置。

## 外观与提醒

设置支持浅色、深色与跟随系统，默认跟随 Windows 外观。选择立即生效并保存。开关仅响应控件本身的点击，标题和说明文字不切换开关状态。

网络状态查询和低流量提醒独立于启动登录运行；没有保存凭据但网络已在线时同样可以查询。低流量提醒使用学校接口返回的剩余额度；首页三段流量条按[流量口径](statistics.md)单独计算。

## 软件更新

1.1.0 起，在「设置 → 软件更新」检查新版、查看说明并下载。下载完成后点击「重启并更新」，确认后助手会短暂关闭并重新打开。账号和设置会保留，校园网连接不会主动断开。

默认自动检查，但不会自动下载或重启。更新默认跟随 Windows 系统代理，可改为直接连接；校园网登录和查询始终直连。1.0.0 用户需先手动替换程序升级到 1.1.0。

用户数据目录中的 `updater.json` 保存更新设置与版本缓存，`.updates/` 保存更新文件和恢复信息。这些文件也不应提交到 GitHub。详见[自动更新说明](updating.md)。
